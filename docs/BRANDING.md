# Branding and UI Guidance

The supplied logos / wordmarks should be included in the design assets directory and used consistently.

Visual direction (from brief)
- Serious, technical, calm, evidence-oriented, enterprise decision-support
- Near-white / warm-light background
- Dark charcoal text (serious tone)
- Accent color: restrained deep teal or dark blue
- Subtle borders for cards, moderate rounded corners, lots of whitespace
- No gradients that feel 'startupy', no cartoon imagery, no robot icons

Suggested palette (approximate, tune to supplied wordmark)
- Background (warm near-white): #FBFBF9
- Text (dark charcoal): #111827 (Tailwind slate-900)
- Muted body text: #374151 (slate-700)
- Accent deep-teal / dark-blue: #0F5E8A or #0A6CFF (sample; refine against supplied vector)
- Card border / divider: #E6E9EB

Typography
- System font stack for speed, or a serious geometric sans (like Inter) via local embed
- Font sizes and spacing should favor legibility and print output for memos

Assets
- Place the supplied logo and wordmark in /public/assets/ and reference in header and memo

Microcopy guidance
- Use concise, plain language: "What must be true?", "What is actually measured?", "Who owns the outcome?"
- Avoid hype words: no "transformative", "game-changing", "AI-powered". Use "modeled", "estimated", "input-based" instead.
